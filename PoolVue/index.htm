Venues belong only to this tournament. Pools are automatically placed on available venues in stage order.

Tournament venues Examples: Table 1, Table 2, Main room.
A pool uses one venue. Its estimated duration is the number of matches in the pool × game length. Pools in the same stage run in parallel where venues are available. When closing time is reached, scheduling pauses and continues from opening time the next day; the next stage starts after the previous stage is estimated to finish.
